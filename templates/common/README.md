# {{PROJECT_NAME}}

Express backend generated by [instant-express](https://www.npmjs.com/package/instant-express).

## Run it

```bash
npm run dev      # development, restarts on file changes
# @if ts
npm run build    # compile TypeScript to dist/
# @endif
npm start        # production
# @if tests
npm test         # run tests
# @endif
```

Settings live in `.env` (copy `.env.example` on a new machine). Never commit `.env`.

## API

| Method | Route | What it does |
|--------|-------|--------------|
| GET | `/api/health` | Health check |
# @if auth
| POST | `/api/auth/signup` | Create account `{ name, email, password }` |
| POST | `/api/auth/login` | Log in `{ email, password }` |
| POST | `/api/auth/logout` | Log out |
| GET | `/api/auth/me` | Logged-in user (needs login) |

Login sets an **httpOnly cookie** named `token`. From the frontend, send requests with
`credentials: 'include'` (fetch) or `withCredentials: true` (axios), and set `CLIENT_URL` in `.env`
to your frontend's URL.
# @endif

## Folder structure

```
src/
  server.{{EXT}}        starts the server (and connects the DB)
  app.{{EXT}}           middlewares + routes
  config/          env variables, database
  routes/          URL → controller
  controllers/     request handling
  models/          database schemas
  middlewares/     auth, errors
  utils/           helpers (AppError)
```

## Adding a new feature (example: posts)

1. `src/models/Post.{{EXT}}` — the schema
2. `src/controllers/postController.{{EXT}}` — functions like `getPosts`, `createPost`
3. `src/routes/postRoutes.{{EXT}}` — `router.get('/', getPosts)`
4. `src/app.{{EXT}}` — `app.use('/api/posts', postRoutes)`

Throw `new AppError(404, 'Post not found')` for errors — the error middleware sends the response.
No try/catch needed (Express 5 catches async errors).
